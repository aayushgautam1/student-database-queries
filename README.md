# Student Database SQL Project

## About the Project

This project was part of my database coursework. The goal was to work with a provided student database and use SQL queries to retrieve, organize, and analyze different types of information.

I completed a set of 10 tasks using MySQL, covering data filtering, sorting, counting, grouping, and basic data analysis.

## Tasks Completed

1. Displayed students' first names, last names, and groups, sorted by group and last name.
2. Counted the total number of students.
3. Counted the number of male and female students.
4. Found the number of active students living in cities.
5. Retrieved unique groups in reverse order.
6. Filtered students born between specified dates.
7. Displayed the 20 oldest students, including their current ages.
8. Listed cities and districts with the number of people living in each.
9. Counted the different groups and students in each group.
10. Identified the statuses with the highest and lowest student counts.

## Technologies Used

- MySQL
- SQL
- phpMyAdmin
